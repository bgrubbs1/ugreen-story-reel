# Disclosures and principal functionality

Required disclosure for the Round 1 Pre-test Skill Package. This file is linked from `SKILL.md`.

## Principal functionality developed for this Hackathon

The original work in this package is the orchestration design and its written specification: the memory-story workflow, the evidence and anti-invention rules, the approval gate before state changes, the two-to-five chapter constraint, the state and recovery matrix, and the delegation prompts for the photo, document and knowledge experts. This Skill package is Markdown-only and contains no executable code.

## Third-party components and supported platform capabilities

- Official UGOS Skill Creation Tool / Uliya Skill Kit (`uliya-skill-kit`): used as the authoring and static-validation tool for this Skill. Source: UGREEN Hackathon Starter Kit (https://ai.ugreen.com/pages/hackathon-starter-kit). The kit is not redistributed in this ZIP.
- Supported UGOS CLI capabilities, used through registered experts as declared in `SKILL.md`: `ug-photo` (photo and album Actions), `ug-document` (document writing and question answering), `ug-knowledge` (saving text). These are platform capabilities of the UGREEN AI NAS, not third-party libraries.
- Markdown text only. No third-party Markdown libraries, no open-source code libraries, no bundled fonts, images or data.
- No third-party data, model weights or training datasets are included or required. The skill is designed to use the NAS local AI model through the platform experts.

## AI tools used and their principal uses

- An AI coding assistant was used as a drafting tool to structure and edit this Markdown specification, to check it against the official Skill format, and to prepare the Round 1 proposal and documentation. Its principal uses were drafting, consistency review, and static checking.
- The entrant directs the work, reviews every statement, decides the product behavior, and owns the submission. The submission is the entrant's original work product; no person outside the entrant's team developed the Project or created the submission materials.
