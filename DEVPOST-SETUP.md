# Devpost setup: exact Round 1 upload path (user-only actions)

The authoring agent did **not** create accounts, register, join, submit, or contact organizers. Everything
in this file is done by the entrant in the browser. This file only removes ambiguity and gives a
time-boxed checklist.

- Hackathon page: https://ugreenhackathon.devpost.com/
- Manage submissions page: https://devpost.com/submit-to/31552-ugreen-hackathon-2026-on-ai-nas/manage/submissions
- Round 1 deadline: **2026-11-15 11:45 pm PT = 2026-11-16 02:45 ET**. Hard stop.

## Before you start (5 minutes, one-time)

- [ ] Devpost account exists and you are signed in (account creation is a user-only step; do not store
      credentials in this repo or in any file here).
- [ ] On https://ugreenhackathon.devpost.com/ you have clicked **"Join Hackathon"**. The button turns
      into a "joined" state; the manage-submissions page only works after joining.
- [ ] You have the two files locally ready to upload:
      - `proposal/round1-proposal.pdf` (PDF, 14,526 bytes, 3 pages, ten answers = 487 words)
      - `pre-test-skill-package.zip` (ZIP, 7,284 bytes, `SKILL.md` at root + 3 Markdown references)
- [ ] Track chosen: **Bring Memories to Life**.

## Click path (typical Devpost flow)

Devpost's UI labels can change; where a label is not guaranteed, a plausible alternative is given.
The page was **not fetched with a logged-in session from this environment** because the manage page
requires the entrant's own authentication - treat the exact button text as **UNVERIFIED** and follow
what the page shows.

1. Open https://devpost.com/submit-to/31552-ugreen-hackathon-2026-on-ai-nas/manage/submissions
   (if prompted, sign in first, then re-open the link).
2. If you have no submission yet, click **"Create a submission"** / **"New submission"** /
   **"Start a submission"**.
3. If a project already exists, click **"Edit submission"** / **"Continue submission"** on the
   Story Reel project (do not create a second project - the rules allow one Project per entrant).
4. Fill the required fields:
   - **Project name:** `Story Reel`
   - **Elevator pitch / tagline:** from [`SUBMISSION.md`](SUBMISSION.md#field-2-tagline--elevator-pitch-short-one-line)
   - **Description / About the project:** from [`SUBMISSION.md`](SUBMISSION.md#field-3-description--about-the-project)
   - **Track / theme:** select `Bring Memories to Life` (must be exact).
5. **Upload the PDF**: Project Proposal / "Upload a file" slot -> `proposal/round1-proposal.pdf`.
   Wait for the upload to finish and confirm the filename appears.
6. **Upload the ZIP**: Pre-test Skill Package / "Upload a file" slot ->
   `pre-test-skill-package.zip`. Confirm the filename appears; the ZIP is well under 10 MB.
7. Leave the optional video / repo / website fields empty for Round 1 (a demo video is not required and
   there is no public repo link required). Do not add private links.
8. Click **"Save draft"** / **"Save"** (whatever the page offers) first.
9. Re-read the preview: project name, tagline, description, track, and both filenames.
10. Click **"Submit"** / **"Submit project"**. Confirm the page shows a submitted/complete state.
11. Re-open the manage page and confirm the submission shows both attachments and the submitted status.
12. Do **not** delete the submission or the Round 1 materials afterwards (rules require keeping them).
